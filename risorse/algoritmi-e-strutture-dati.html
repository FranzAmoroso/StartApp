Prima di cominciare

Gli strumenti per leggere ogni analisi di complessità (CLRS capitoli 2, 3 e 4).

Notazione asintotica

O
Limite superiore. f(n) = O(g(n)) se esistono c > 0 e n₀ tali che 0 ≤ f(n) ≤ c·g(n) per ogni n ≥ n₀. “Cresce al più come g.”
Ω
Limite inferiore. f(n) = Ω(g(n)) se 0 ≤ c·g(n) ≤ f(n) da un certo n₀ in poi. “Cresce almeno come g.”
Θ
Limite stretto. f(n) = Θ(g(n)) se vale sia O sia Ω: esistono c₁, c₂ con c₁·g(n) ≤ f(n) ≤ c₂·g(n). “Cresce esattamente come g.”

Caso migliore, medio e peggiore sono cose diverse dalla notazione: per ciascun caso si può dare un O, un Ω o un Θ. Per esempio insertion sort è Θ(n²) nel caso peggiore e Θ(n) nel migliore, quindi in generale è O(n²) e Ω(n).

Come crescono le funzioni

Asse verticale logaritmico, fino a un milione di operazioni. Con n = 20, 2ⁿ supera già il milione; n! ci arriva con n = 10.

Quanto tempo ci vuole davvero

Tempo per eseguire f(n) operazioni su una macchina da un miliardo di operazioni al secondo.

Per questo un algoritmo Θ(n log n) batte un Θ(n²) anche su un computer cento volte più lento, appena n è abbastanza grande (CLRS 1.2).

Il Teorema Master

Per ricorrenze T(n) = a·T(n/b) + f(n) con a ≥ 1, b > 1. Si confronta f(n) con nlogb a (CLRS 4.5):

Caso 1. f(n) = O(nlogb a − ε): vincono le foglie, T(n) = Θ(nlogb a).
T(n) = 9T(n/3) + n → Θ(n²). Strassen: 7T(n/2) + Θ(n²) → Θ(nlg 7) ≈ Θ(n2,81).
Caso 2. f(n) = Θ(nlogb a): ogni livello costa uguale, T(n) = Θ(nlogb a log n).
Merge sort: 2T(n/2) + Θ(n) → Θ(n log n). Ricerca binaria: T(n/2) + Θ(1) → Θ(log n).
Caso 3. f(n) = Ω(nlogb a + ε) e a·f(n/b) ≤ c·f(n) con c < 1: vince la radice, T(n) = Θ(f(n)).
T(n) = 3T(n/4) + n log n → Θ(n log n).

Non copre tutto: T(n) = 2T(n/2) + n log n cade fra il caso 2 e il caso 3 e va risolta con l'albero di ricorsione.

Come si ricava la complessità

Cicli annidati. Si moltiplicano le iterazioni: due cicli fino a n danno Θ(n²). Se il ciclo interno dipende da quello esterno (j da i a n) si somma: Σ(n − i) = Θ(n²).

Dimezzamenti. Un ciclo che dimezza l'intervallo a ogni giro (ricerca binaria, potenza veloce) fa Θ(log n) iterazioni.

Ricorsione. Si scrive la ricorrenza e la si risolve con il Teorema Master, l'albero di ricorsione o la sostituzione (CLRS 4.3-4.5).

Analisi ammortizzata. Quando un'operazione è a volte costosa ma raramente, si guarda il costo totale di una sequenza: lo stack monotono fa Θ(n) push e pop in tutto, anche se un singolo passo può farne molti (CLRS 17).

Spazio extra. Si conta la memoria oltre all'input: array ausiliari, tabelle e anche lo stack delle chiamate ricorsive, che per una ricorsione profonda d costa Θ(d).

Grafi. Con liste di adiacenza una visita costa Θ(V + E): ogni vertice si visita una volta e ogni arco si esamina una (orientato) o due volte (non orientato).
